# ねむりの丘 · 잠드는 언덕

1990년대 일본 OVA 셀 애니 스타일의 80초 단편입니다. 그림·움직임·소리를 모두 코드로 만들고, 외부 파일 없이 HTML 하나로 돌아갑니다.

| 파일 | 용도 |
|---|---|
| `rainy-robot-ova.html` | 16:9 가로판. 브라우저에서 바로 재생 |
| `rainy-robot-ova-tiktok.html` | 9:16 세로판(1080×1920). 틱톡·쇼츠·릴스용 구도이고, 영상 렌더링의 원본 |
| `tools/render-video.js` | 세로판 프레임(JPEG)과 사운드트랙(WAV) 추출 |
| `tools/encode-tiktok.sh` | 추출본을 MP4(H.264/AAC, -14 LUFS, 약 66MB)로 인코딩 |

조작: 재생 버튼 → 화면 터치 또는 Space 일시정지 · R 처음부터 · F 전체화면

## 스타일 규칙
- 굵은 외곽선과 2단 셀 칠(밝은 면/그림자 면)은 인물에만 씁니다. 배경은 선 없이 그러데이션 페인팅으로 그립니다.
- 캐릭터는 12fps(2콤마)로, 화면 출력은 24fps로 움직입니다.
- 화면 효과: 필름 입자, 하레이션(빛 번짐), 비네트, 미세한 화면 흔들림, 먼지 티끌
- 음악: 72BPM(1마디 3.33초 × 24마디 = 80초), 일렉피아노(FM 합성)와 스트링 패드. 결말에서 오르골이 느려지며 음이 처지다 멈춥니다.

# 모나리자, 오늘 첫 공연 (40초 패러디)

`mona-lisa-aria-tiktok.html`: 9:16, 40초. 레오나르도 다 빈치 〈모나리자〉(1503–1519, 퍼블릭 도메인)를 코드로 다시 그린 초상화가 폐관 직전의 미술관에서 아리아를 부릅니다. 사진이나 이미지 파일은 쓰지 않았습니다.

- **그림:** 풍경, 인물, 이목구비 세 레이어를 화면 해상도로 그리고 확대 배율에 비례해 블러를 줘서 스푸마토를 냅니다. 그 위에 황록색 바니시, 가장자리 어둡기, 화면 기준 1픽셀 균열(크라클뤼르)을 얹습니다.
- **노래:** 새로 작곡한 가사 없는 보칼리제(F장조, 66BPM)입니다. 소프라노는 성문 음원에 모음 포먼트 필터 5개를 걸어 합성합니다(지연 비브라토, 포르타멘토, 고음 F1 튜닝, 숨소리). 반주는 현악, 하프, 베이스, 팀파니, 호른입니다.
- **동기화:** 입 벌림, 모음 모양, 호흡, 눈 감기, 손 올리기는 오디오와 같은 악보 데이터(`SCORE`)에서 계산합니다. 유리 공명과 균열, 휴대폰 셔터, 박수도 같은 시간표를 씁니다.
- `?nocap`을 붙이면 자막 없는 판이 됩니다.

**실제 목소리 입히기**: 권리가 있는 녹음(직접 녹음한 것, 이용 허락을 받은 것, 퍼블릭 도메인 음원)을 넣으면, 입 모양과 연출 전체가 그 녹음에 맞춰 다시 짜입니다.
- 브라우저에서 시작 화면의 「🎤 내 목소리 파일로 재생」을 누르고 오디오 파일을 고르면 됩니다.
- 영상으로 만들 때는 녹음을 HTML에 넣어 빌드한 뒤 길이를 `auto`로 렌더링합니다.
- 분석(`m_voice.js`)은 10ms 단위로 음량, 음높이(옥타브 오류를 보정한 자기상관), 밝기를 뽑습니다. 이 값으로 입 벌림, 노래 시작, 클라이맥스(최고음을 가장 오래 버티는 구간), 마지막 음, 숨, 끝을 찾고, 카메라 컷, 자막, 유리 균열, 박수를 거기에 맞춥니다. 실제 녹음 모드에서는 녹음이 음악을 맡고, 합성 반주는 끄고 미술관 효과음만 겹칩니다.
- **실제 녹음판** `mona-lisa-aria-galli-curci-1921-tiktok.html`: 아멜리타 갈리쿠르치가 부른 비제 〈진주잡이〉의 "Comme autrefois"(1921년 9월 10일 캠던 녹음, 1921년 발매). 위키미디어 공용 등록 파일이고 미국 기준 퍼블릭 도메인입니다(작곡가 1875년 사망, 대본 작가 1903년·1872년 사망). 마지막 약 38초를 잘라 78회전 잡음을 줄이고, 앞에 3.6초 무음을 붙여 미술관 도입부가 먼저 나오게 했습니다. 끝 크레딧에 녹음 출처를 표기합니다.
- 검증: 합성 소프라노의 목소리 트랙을 대역 녹음으로 넣었을 때, 표시점 5개가 악보 정답과 ±0.1초 안에서 맞았고 입 모양 상관계수는 0.89(시간 차 0ms)였습니다.

# 칠판으로 배우는 삼각함수 (약 94초)

`trig-chalkboard-tiktok.html`: 9:16. 분필로 쓰고 지우개로 지우며 진행하는 수업 영상입니다. 칠판, 분필 글씨, 도형, 소리를 모두 코드로 만들었습니다.

- **분필 표현:** 선과 글씨는 진행도에 따라 써 내려가고, 입자 마스크로 가루가 묻어나는 질감을 냅니다. 손에 든 분필이 쓰는 위치를 따라다니고, 장면이 바뀔 때 지우개가 지그재그로 지나가며 분필 가루 흔적을 남깁니다.
- **글꼴:** 손글씨는 나눔손글씨 펜(OFL, © 2010 NHN Corporation)에서 쓰는 글자만 추려 "ChalkFont"라는 이름으로 넣었습니다("Nanum"이 예약 이름이라 이름을 바꿈). 글꼴에 없는 θ, π, √, °, −, 원문자, 별, 체크는 분필 획으로 직접 그립니다.
- **수식:** 분수, 루트, 윗첨자를 손글씨로 배치하는 작은 엔진이 있습니다.
- **소리:** 분필 긁는 소리, 톡 소리, 지우개 소리, 새로 만든 80BPM 로파이 배경 음악입니다. 모든 효과음은 화면과 같은 타임라인 데이터(`SND`)에서 시간을 가져옵니다.

| 장면 | 내용 |
|---|---|
| 제목 | 삼각함수 · sin · cos · tan |
