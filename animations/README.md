# ねむりの丘 · 잠드는 언덕

1990년대 일본 OVA 셀 애니 스타일의 80초 단편입니다. 그림·움직임·소리를 모두 코드로 만들고, 외부 파일 없이 HTML 하나로 돌아갑니다.

| 파일 | 용도 |
|---|---|
| `rainy-robot-ova.html` | 16:9 가로판. 브라우저에서 바로 재생 |
| `rainy-robot-ova-tiktok.html` | 9:16 세로판(1080×1920). 틱톡·쇼츠·릴스용 구도이고, 영상 렌더링의 원본 |
| `tools/render-video.js` | 세로판 프레임(JPEG)과 사운드트랙(WAV) 추출 |
| `tools/encode-tiktok.sh` | 추출본을 MP4(H.264/AAC, -14 LUFS, 약 66MB)로 인코딩 |

조작: 재생 버튼 → 화면 터치 또는 Space 일시정지 · R 처음부터 · F 전체화면

## 스타일 규칙
- 굵은 외곽선과 2단 셀 칠(밝은 면/그림자 면)은 인물에만 씁니다. 배경은 선 없이 그러데이션 페인팅으로 그립니다.
- 캐릭터는 12fps(2콤마)로, 화면 출력은 24fps로 움직입니다.
- 화면 효과: 필름 입자, 하레이션(빛 번짐), 비네트, 미세한 화면 흔들림, 먼지 티끌
- 음악: 72BPM(1마디 3.33초 × 24마디 = 80초), 일렉피아노(FM 합성)와 스트링 패드. 결말에서 오르골이 느려지며 음이 처지다 멈춥니다.

# 〈하울의 움직이는 성〉 60초 패러디 요약 (팬메이드)

`howl-parody-ova-tiktok.html`: 9:16, 60초, 같은 OVA 엔진으로 만든 자막형 개그 요약입니다. 영화판 줄거리를 우리 말로 요약했습니다.

**저작권 가드레일**
- 원작 소설·영화의 캐릭터와 성 디자인, 로고·제목 서체, 주제곡과 그 멜로디, 대사는 쓰지 않았습니다.
- 등장인물은 모두 오리지널 디자인이고, 자막에서는 역할 별명으로 부릅니다(모자집 장녀, 거울 중독 마법사, 숯불 악마, 황무지 마녀, 양동이 허수아비, 걷는 집).
- 음악은 새로 작곡했습니다. 원작 테마를 연상시키지 않도록 3/4 왈츠는 쓰지 않았습니다.
- 원작 제목은 오프닝 라벨에 일반 텍스트로만 표기하고, 끝에 「팬메이드 패러디 · 그림과 음악은 직접 제작」 문구를 넣었습니다.
- 자막 글꼴: Black Han Sans 일부 글자만 추려 임베드했습니다. © 2015 The Black Han Sans Project Authors, SIL OFL 1.1

**URL 옵션**: `?nocap`을 붙이면 자막 없는 판이 됩니다(틱톡 앱의 텍스트 음성 변환으로 목소리를 붙일 때 사용).

**3D 무대 (Kenney CC0)**: 2·3·5·7·8·9·12컷은 `assets/kenney/3d`의 Fantasy Town Kit, Nature Kit, Furniture Kit 모델 63개로 만든 무대 위에서 진행됩니다. 2D 손그림 캐릭터는 3D 지면 좌표를 화면에 투영한 위치에 세웁니다.
- three.js(MIT)로 셀 셰이딩(2단 톤 램프)과 안개를 입혀 OVA 배경 미술 톤에 맞췄습니다.
- 걷는 집은 Kenney 블록을 우리 디자인대로 조립했습니다(집 다섯 채 탑, 황동 게 다리, 패치워크 날개). 주인공급 오브젝트라 잉크 외곽선(뒷면 확장 방식)을 넣었습니다.
- 쓰는 모델만 골라 HTML에 내장해서 파일 하나(약 1.9MB)로 돌아갑니다. WebGL이 없으면 기존 2D 무대로 자동 대체됩니다.
