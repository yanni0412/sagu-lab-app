# 도어온 — 스마트 도어락 원격 제어 앱 (프로토타입)

크라운 같은 원격 도어락 앱을 참고해 만든 **단일 HTML 웹앱**입니다.
지금은 실제 도어락 대신 **가상 도어락(MockLockDriver)** 으로 동작하므로
설치 없이 바로 눌러보며 화면·흐름을 확인할 수 있어요.

## 실행

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/doorlock/ 열기 (휴대폰 화면 크기 권장)
```

## 기능

| 탭 | 기능 |
|---|---|
| 홈 | 잠금 상태, **길게 눌러 원격 열기**(실수 방지), 눌러서 잠그기, 배터리·문 상태·자동잠금, 최근 출입 |
| 출입기록 | 날짜별 기록, 열림/잠김/경고 필터 |
| 출입키 | 임시 비밀번호(1회용 / 기간 / 요일·시간 반복) 생성·공유·삭제, 구성원 초대·권한 |
| 설정 | 자동잠금(시간), 이중잠금(원격 열기 차단), 침입 경보, 음량, 앱 비밀번호(실행·원격 열기 시 확인), 알림 종류, 도어락 추가/삭제 |

**데모 시뮬레이터**(설정 탭): 가족 지문 출입, 키패드 번호 입력(임시 비밀번호 검증, 5회 오류 시 침입 경보),
문 열어두기(10초 후 알림), 배터리 감소, 연결 끊김을 흉내 낼 수 있어요.

데이터는 브라우저 `localStorage`에만 저장됩니다. 앱 비밀번호는 SHA-256 해시로 저장해요.

## 실제 도어락과 연결하려면

`index.html`의 **3. 도어락 드라이버** 부분만 바꾸면 됩니다.
모든 명령은 `driver.send(device, "lock" | "unlock")` 한 곳을 거칩니다.

1. **제조사 클라우드 API가 있는 경우** — 포함된 `HttpLockDriver`를 쓰거나 수정합니다.
   ```js
   const driver = new HttpLockDriver("https://내서버/api", 토큰);
   ```
   단, **API 키·토큰을 앱 코드에 넣으면 안 됩니다.** 자체 서버(백엔드)를 두고
   로그인한 사용자별 토큰으로 호출하세요.
2. **블루투스(BLE) 직접 연결** — Capacitor BLE 플러그인(예: `@capacitor-community/bluetooth-le`)으로
   `send()`를 구현합니다. 도어락의 BLE 프로토콜(서비스 UUID, 명령 포맷, 암호화)은
   제조사에서 공개하거나 SDK를 제공해야 쓸 수 있어요.
3. **Wi-Fi 게이트웨이/허브형** — 대부분 Tuya·SmartThings 같은 플랫폼을 거칩니다.
   해당 플랫폼의 개발자 API를 서버에서 호출하는 구조가 안전합니다.

출입 기록·푸시 알림도 실서비스에서는 서버가 도어락 이벤트를 받아 저장하고
FCM 같은 푸시로 보내야 합니다(지금은 앱 안 토스트·알림함으로만 표시).

## Android 앱으로 만들기

이 저장소의 Capacitor 설정(`capacitor.config.ts`)은 당구 앱(`www/`)을 가리키고 있어요.
도어락 앱을 따로 출시하려면 **새 저장소/폴더**에 Capacitor 프로젝트를 만들고
`doorlock/index.html`을 그 프로젝트의 `www/index.html`로 복사하는 것을 권장합니다
(앱 ID가 달라야 Play 스토어에 별도 앱으로 올라갑니다).
