# Kenney assets

Game assets by Kenney (https://kenney.nl), licensed CC0 1.0 (public domain).
Each pack keeps its original `License.txt`.

| Pack | Source | Contents |
|---|---|---|
| `prototype-kit` | https://kenney.nl/assets/prototype-kit | 3D models (`Models/GLB format/*.glb`, textures in `Models/GLB format/Textures/`), previews |
| `prototype-textures` | https://kenney.nl/assets/prototype-textures | Grid textures (`PNG/`, `Vector/*.svg`) |
| `interface-sounds` | https://kenney.nl/assets/interface-sounds | UI sound effects (`Audio/*.ogg`) |
| `ui-pack` | https://kenney.nl/assets/ui-pack | UI images (`PNG/`, `Vector/`), fonts (`Font/`), sounds (`Sounds/`) |

Removed from the original downloads to keep the app small:
FBX and OBJ copies of the prototype-kit models (the GLB files are the same models),
`.url` shortcuts, `.swf` (Flash) files and `Overview.html`.
