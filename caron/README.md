# 카온 (CarOn) — 차량 원격제어 앱

크라운 원격시동/도어락 앱처럼 휴대폰 **블루투스**로 차량을 제어하는 앱입니다.
화면은 이 폴더의 `index.html` 한 파일이고, Android APK는 `caron-app/`(Capacitor)에서 빌드합니다.

| 탭 | 기능 |
|---|---|
| 제어 | 차량 그림(비상등 깜빡임·트렁크·시동 배기 표시), 블루투스 연결 버튼, **잠금 / 열기 / 트렁크(길게) / 차량 찾기**, 가운데 **START·STOP(길게 눌러 원격 시동)** |
| 설정 | 근접 자동 열림, 멀어지면 자동 잠금, 흔들어서 잠금/열림, 기기 검색, 이름 변경, 차량 번호, 원격 시동 시간, 기기 비밀번호(보안 키) 변경, 앱 잠금 비밀번호, 버전 정보 |
| 기록 | 잠금·열림·시동·경보 기록 (날짜별) |
| 정보 | 사용법, 보안 방식, 안전 주의 |

기기가 없으면 **데모 모드**(가상 차량)로 모든 기능을 체험할 수 있어요.

## 실행 (브라우저)

```bash
python3 -m http.server 8000      # 저장소 루트에서
# http://localhost:8000/caron/  (휴대폰 크기 화면 권장)
```

## APK 설치

1. GitHub → **Actions** → **Build CarOn APK** → 최신 실행 → **Artifacts**의 `caron-debug-apk` 다운로드
   (`caron/`이나 `caron-app/`을 수정해 push하면 자동 실행, 수동 실행도 가능)
2. 압축을 풀어 나온 `app-debug.apk`를 휴대폰에 설치 ("출처를 알 수 없는 앱" 허용)
3. 첫 실행 때 블루투스·위치 권한 허용

디버그 APK라 Play 스토어에는 올릴 수 없어요. 스토어용은 루트 README의 서명 AAB 방식을 따라 하세요.

## 차량 기기 만들기 (ESP32)

`caron-app/firmware/caron_esp32/caron_esp32.ino` — Arduino IDE + ESP32 보드 패키지로 업로드.

| 출력 (릴레이) | 기본 핀 | 입력 (선택) | 기본 핀 |
|---|---|---|---|
| 잠금 / 열림 펄스 | 25 / 26 | 보닛 스위치 (열림=LOW) | 19 |
| 트렁크 펄스 | 27 | 브레이크 (밟음=LOW) | 18 |
| 경적·비상등 | 33 | 도어 실내등 선 (열림=LOW) | 5 |
| 점화 유지 / 스타터 | 32 / 13 | 충격 센서 | 17 |
| | | 배터리 전압 ADC | 34 |

1. 업로드 후 시리얼 모니터(115200)에 나오는 **32자리 보안 키**를 확인
2. 앱 → 설정 → **기기 검색** → 키 입력 → `CarOn` 선택

**가장 쉽고 안전한 연결법**: 차에 이미 달린 리모컨(원격시동기·경보기)의 버튼 접점에 릴레이나
포토커플러를 병렬로 붙여 "버튼을 대신 눌러 주는" 방식이에요. 점화·스타터를 직접 배선하는 건
차종별 이모빌라이저·안전회로 때문에 위험하니 전문 설치점이나 상용 원격시동 모듈을 이용하세요.

펌웨어 안전 장치: 보닛 열림·브레이크 밟음이면 원격 시동 거부, 원격 시동 중 브레이크를 밟으면 즉시 끔,
설정한 시간이 지나면 자동으로 끔, 열고 30초 안에 문을 열지 않으면 다시 잠금, 잠긴 상태에서 문이 열리면 경보.

## 보안

- 명령마다 기기가 **일회용 난수**를 주고 앱이 `HMAC-SHA256(보안 키, 난수‖명령)`으로 서명 → 키 없이는 조작할 수 없고, 엿들은 신호를 다시 보내도 안 통해요.
- 잘못된 키로 5번 시도하면 30초 차단 + 경보 기록.
- **기기 비밀번호 변경**: 기기가 새 키를 만들어 기존 키로 암호화해 보내고, 앱이 새 키로 확인해야 확정돼요(중간에 끊겨도 기존 키 유지).
- 보안 키는 기기에서 무작위로 생성돼요(기본 키 없음). BOOT 버튼 5초 = 키 초기화.

### 알려진 한계

- 원래 크라운 기기와는 통신 규격이 달라 **연결할 수 없어요.** 크라운 기기 규격은 공개돼 있지 않아요.
- 근접 자동 열림은 APK가 화면에 켜져 있을 때만 동작해요(백그라운드 동작은 네이티브 서비스가 필요).
- 차의 원래 리모컨으로 잠그거나 연 것은 기기가 알 수 없어서, 앱의 잠김 표시와 다를 수 있어요.
- 상태 알림(잠김/시동)은 암호화되지 않아 근처에서 엿보면 상태를 알 수 있어요(조작은 불가).
- 앱의 보안 키는 휴대폰 `localStorage`에 저장돼요. 휴대폰을 잃어버리면 BOOT 5초로 키를 바꾸세요.
- ESP32 펌웨어는 Arduino IDE에서 컴파일해 보세요. (이 저장소의 클라우드 러너는 Arduino 패키지 서버 접속이 간헐적으로 막혀 컴파일 자동검사를 걸지 않았어요.) 실제 차량 테스트도 아직 안 했어요.
- **크라운/MP686 모듈을 쓸 때는 ESP32 펌웨어가 필요 없어요.** ESP32는 직접 기기를 만들 때만 써요.
