# Kenney assets (library)

Game assets by Kenney (https://kenney.nl), licensed CC0 1.0 (public domain).
Each pack keeps its original `License.txt`.

This folder is a library kept in the repository only. It is **not** part of the app:
Capacitor bundles `www/` only. Copy the files you need into `www/assets/` to use them
in the app (the packs already in `www/assets/kenney/` are separate copies).

- `2d/`: the 50 newest 2D packs as listed on kenney.nl on 2026-11-18 (79 MB)
- `3d/`: all 50 3D packs on kenney.nl on 2026-11-18 (193 MB)

Removed from the original downloads to keep the repository small:
FBX, OBJ/MTL, DAE and STL copies of 3D models when the pack has glTF/GLB versions
(`animated-characters-*` have no glTF and keep their original formats),
`.url` shortcuts, `.swf` (Flash) files, Unity packages and `Overview.html`.
